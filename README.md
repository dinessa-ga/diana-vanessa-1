
# Diana Vanessa Portfolio

A modern, interactive portfolio website showcasing my work as a Tech Content Strategist. This project highlights branding projects, case studies, skills, and services, built with a focus on clean design and user experience.

## Features

This portfolio now includes **two main pages**:

- **Creative Portfolio** (`/`):
   - Hero Section: Eye-catching introduction with key highlights.
   - Branding Showcase: Display of featured branding projects with images, colors, and services.
   - About Section: Personal overview and background.
   - Skills Section: Showcase of technical and creative competencies.
   - Contact Form: Easy way for visitors to get in touch.
   - Case Studies: Detailed project breakdowns with client overviews, challenges, strategies, and results.
   - Hash-Based Routing: Seamless navigation between home and individual case studies.

- **Developer Portfolio** (`/dev`):
   - Hero Section: Introduction focused on development profile.
   - About Section: Developer background and experience.
   - Projects: List of development projects with details.
   - Services: Development services offered.
   - Contact Form: Contact for development inquiries.

**Global Features:**
- Dark/Light Theme Toggle: User-friendly theme switching.
- Responsive Design: Optimized for desktop, tablet, and mobile devices.
- Modern UI components and smooth navigation between both pages.

## Tech Stack

- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS with custom utilities
- **UI Components**: Radix UI primitives for accessibility
- **Icons**: Lucide React
- **Animations**: Motion library
- **Theme Management**: next-themes
- **Charts**: Recharts (if used in skills or data visualization)
- **Forms**: React Hook Form with validation

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd diana-vanessa-1


## Running the code

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

The app will be available at `http://localhost:5173` (or the port shown in your terminal).

## Usage & Navigation

- Visit `http://localhost:5173/` for the **Creative Portfolio** (branding, content, case studies).
- Visit `http://localhost:5173/dev` for the **Developer Portfolio** (projects, dev services).
- Use the navigation menu to switch between both pages.
- The site is fully responsive and supports dark/light mode.
